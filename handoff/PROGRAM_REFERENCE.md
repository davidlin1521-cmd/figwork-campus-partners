## Current naming

- Public program name: **Figwork Student Ambassador Program**
- Selected participants may use **Figwork Campus Growth Partner**, **Figwork Campus Partner**, or **Figwork Student Ambassador** on a resume or professional profile.
- Open referral participants are not part of the selected campus program and may not use those titles or receive the brand kit.

## Current reward rules shown publicly

- Open referral program: **$5 per verified activation**
- Selected Campus Growth Partners: **$10 per verified activation**, beginning from selection for new referrals
- Annual cap: **$2,000 per participant per calendar year**
- Attribution window: **14 days**
- Verification hold: approximately **10 days**

These values are repeated in the marketing page, terms, tests, and referral-infrastructure documents. Changing one requires reviewing all of them.

## Application behavior

The selected campus program requires an application. The open referral program does not. Visitors find their personal open-referral link inside their Figwork account.

On the website, every Apply button scrolls to the embedded Tally application at the bottom of the program page. The standalone Tally URL remains available for direct sharing.

## Contact and ownership

Program questions and terms questions use `businessdevelopment@figwork.ai`. The repository is public for handoff and cloning, but no open-source license is granted; the contents remain Figwork proprietary unless Figwork explicitly adds a license.
