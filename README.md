# Figwork Campus Partners

A single-page, responsive marketing site for the Figwork Campus Partners student referral program. The page uses vinext, React, TypeScript, and Tailwind's CSS pipeline.

## Local preview

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Before review

Replace the three explicit placeholders in `app/page.tsx`:

- `TODO: LOGO_ASSET`
- `TODO: TALLY_FORM_URL`
- `TODO: CONTACT_EMAIL`

The official logo must be used unmodified. Keep the site local until the paid-referral program clears legal review.

## Validation

```bash
npm test
```
